# Todo List App

A simple Todo List application made using HTML, CSS and JavaScript.

This project lets you add, edit, delete and mark tasks as completed. All tasks are stored in Local Storage, so they remain available even after refreshing the page.

## Features

- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Data saved using Local Storage
- Responsive UI

## Tech Stack

- HTML
- CSS
- JavaScript

## Folder Structure

```
todo-list-app/
│── index.html
│── style.css
│── script.js
│── README.md
```

## Run Locally

Clone the project

```bash
git clone https://github.com/Kartikbhakre/todo-list-app.git
```

Open the project folder and run `index.html` in your browser.
